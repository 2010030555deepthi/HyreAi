# Candidate Management Portal

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB

## Features

- Login
- View All Candidates
- View Candidate Details
- Add Candidate
- Edit Candidate
- Delete Candidate

## Run Backend

cd backend
npm install
npm run dev

## Run Frontend

cd frontend
npm install
npm run dev
